# ESP Hosting

Одностраничный сайт хостинга в японском стиле: васи-бумага, тушечные горы, красное солнце, лепестки сакуры и печати-ханко. Без фреймворков и сборки — чистые HTML, CSS и JavaScript.

## Запуск

Просто откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 4173
```

и перейдите на `http://127.0.0.1:4173/`.

## Что внутри

- Кинематографичный герой с восходом, параллаксом облаков и анимированными лепестками.
- Три выделенных сервера: **Kitsune · 狐**, **Tengu · 天狗**, **Ryujin · 龍神**.
- Выбор тарифа с печатью «選», липкая панель выбранного сервера и кнопка оплаты.
- Модальное окно оплаты: карта, СБП с QR-кодом, криптовалюта.
- Валидация карты, форматирование полей, состояние загрузки и экран успеха с ханко «完了».
- Адаптивность до 320 px, поддержка `prefers-reduced-motion`, клавиатурная навигация и `Esc` для закрытия окна.

## Настройка

**Тарифы.** Данные для панели и оплаты лежат в объекте `plans` в начале `app.js`. Цены, описания и характеристики карточек — в `index.html` (атрибут `data-plan` связывает карточку с тарифом).

**Реальная оплата.** Сейчас это демо-интерфейс: функция `processPayment()` в `app.js` имитирует запрос и показывает экран успеха. Замените её на вызов платёжного API (ЮKassa, CloudPayments, Stripe и т. п.), а форму карты — на виджет провайдера. В тексте рядом с кнопкой уже указано, что списаний нет; при подключении оплаты уберите эту пометку.

**Контакты и ссылки.** Телефон, почта и Telegram находятся в шапке и подвале `index.html`.
